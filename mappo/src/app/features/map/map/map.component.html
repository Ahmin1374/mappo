Drawing Instructions

  • Use the drawing toolbar on the left to create shapes
  • Click the Polygon tool to draw custom polygons
  • Click the Rectangle tool to draw rectangles
  • Click and drag to create shapes
  • Double-click to finish drawing a polygon
  • Use the edit tools to modify or delete shapes

Admin/Broker Features

  • ✅ Create new regions by drawing shapes
  • ✅ Edit existing regions
  • ✅ Delete regions
  • ✅ Export region data

Viewer Features

  • ✅ View all regions
  • ✅ Search and filter regions
  • ✅ Load regions in map bounds
  • ❌ Cannot create, edit, or delete regions

Backend Integration

  • ✅ Regions are automatically loaded from the database
  • ✅ Use "Load in Bounds" to filter regions by map view
  • ✅ Drawn shapes can be saved to the database
  • ✅ All regions are persisted with user authentication

Note: All drawn shapes are automatically converted to GeoJSON format and can be saved to the backend.
